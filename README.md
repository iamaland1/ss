# سیرات | بەرنامەی ئیسلامی

ئەم پڕۆژەیە وێب-ئەپی **Sirat** ـە، بە React و TypeScript و Vite دروست کراوە. ڕووکارەکە ڕەنگی شینی تۆخ و زێڕینی گەرم دەپارێزێت و زمانەکانی کوردی سۆرانی، عەرەبی و ئینگلیزی پشتگیری دەکات.

## تایبەتمەندییە سەرەکییەکان

- کاتی پێنج نوێژ و هەڵبژاردنی شار.
- قورئانی پیرۆز.
- دوعا و زیکر.
- تەسبیحی ئەلیکترۆنی.
- قیبلەنما.
- تەقویمی کۆچی.
- پەیام و ڕاگەیاندن.
- ڕێکخستنەکان: دەنگی بانگبێژ، شوێن، زمان، ڕووکار و ئاگادارکردنەوە.
- داشبۆردی بەڕێوەبەر.

## ڕێکخستنی فایلەکان

### `src/`
کۆدی سەرەکی ئەپەکە.

### `src/App.tsx`
ناوەندی بەڕێوەبردنی ئەپەکە؛ تابەکان، زمان، ڕووکار، ڕاگەیاندن و گواستنەوەی نێوان بەشەکان لێرە ڕێکدەخرێن.

### `src/components/`
هەر فایلێک بەشێکی دیاریکراوی ڕووکارەکەیە:

- `Navbar.tsx` — شریتی سەرەوە و دوگمەکانی خێرا.
- `PrayerTimes.tsx` — کاتی نوێژەکان.
- `Quran.tsx` — قورئانی پیرۆز.
- `QuranDuas.tsx` — دوعا قورئانییەکان.
- `TasbihView.tsx` — تەسبیح.
- `QiblaView.tsx` — ئاراستەی قیبلە.
- `CalendarView.tsx` — تەقویم.
- `MessagesView.tsx` — پەیام و ڕاگەیاندن.
- `Settings.tsx` — هەموو ڕێکخستنەکان.
- `SettingsModal.tsx` — مۆداڵی کردنەوەی ڕێکخستنەکان.
- `InteractiveMapPicker.tsx` — هەڵبژاردنی شوێن لەسەر نەخشە.
- `AdminDashboard.tsx` — داشبۆردی بەڕێوەبەر.

### `src/data/`
داتای ناوخۆیی ئەپەکە:

- `cities.ts` — شار و کۆئۆردیناتەکان.
- `translations.ts` — وەرگێڕانی سێ زمان.
- `adhanVoices.ts` — لیستی دەنگی بانگبێژ و ڕێکخستنە بنەڕەتییەکان.
- `quranData.ts` — داتای قورئان.
- `quranDuasData.ts` — داتای دوعاکان.
- `adhkarData.ts` — داتای زیکرەکان.

### `src/services/`
لۆجیک و خزمەتگوزارییەکان:

- `prayerTimes.ts` — حیسابکردنی کاتی نوێژ.
- `hijriCalendar.ts` — زانیاریی تەقویمی کۆچی.
- `soundEffects.ts` — پەخشکردن و وەستاندنی دەنگ.
- `announcementsService.ts` — بارکردنی ڕاگەیاندنەکان.

### `src/types/index.ts`
جۆرەکانی TypeScript بۆ داتا و پێکهاتە هاوبەشەکان.

### `src/index.css`
ڕەنگ و ستایلی گشتی، ڕووکارەکانی تاریک/ڕووناک، focus، responsive و کەمکردنەوەی جوڵە.

### `data/announcements.json`
فایلی ڕاگەیاندنەکان بۆ ژینگەی ئەو پڕۆژەیەی کە بەکاردێت.

## دامەزراندن و کارپێکردن

پێویستە Node.js دامەزرابێت.

```bash
npm install
npm run dev
```

بۆ دروستکردنی وەشانی بڵاوکردنەوە:

```bash
npm run build
```

بۆ پشکنینی جۆری TypeScript:

```bash
npm run lint
```

## تێبینیی گۆڕانکارییەکان

- ناوی فایلەکانی بەشە سەرەکییەکان ڕوونتر کراون: `SettingsView.tsx` بووە `Settings.tsx`، `PrayerTimesView.tsx` بووە `PrayerTimes.tsx`، `QuranView.tsx` بووە `Quran.tsx` و `QuranDuasView.tsx` بووە `QuranDuas.tsx`.
- هەموو import ـە پەیوەندیدارەکان نوێکرانەوە.
- کۆمێنتی سەرەوە بۆ فایلە سەرەکییەکان زیاد کرا بۆ ڕوونکردنەوەی ئەرکی هەر فایل.
- ڕووکارەکە بە هەمان ناسنامەی شینی تۆخ و زێڕینی پڕۆژەکە ماوەتەوە؛ focus ـی کیبۆرد، safe-area و reduced-motion زیاد کراون.
- هیچ داتای نوێی ناوەڕۆکی ئایینی زیاد نەکراوە.
